# Ashley's Carnival Rush — support & privacy

The public pages for the iOS game. App Store Connect requires a reachable
support URL and privacy policy URL, and these are those pages.

- `index.html` — about the game
- `privacy.html` — the privacy policy
- `support.html` — support and FAQ

They are deliberately separate from the studio-wide pages on pfdatastack.com,
which describe subscriptions, billing and account deletion. This game has no
account, no purchases and no network connection of any kind, so those pages
would tell a reviewer the opposite of the truth.

The game's source lives in a private repository. Nothing here is generated —
each page is self-contained: an inline SVG favicon and Google Fonts, no local
assets and no build step.
